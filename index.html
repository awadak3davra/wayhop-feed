WayHop package feed

Native OpenWrt / Entware / Keenetic packages for WayHop — 0.5.8. Prefer a one-shot install instead? See the README install guide.

OpenWrt 25.12+ · apk

wget -O /etc/apk/keys/wayhop.pem https://awadak3davra.github.io/wayhop-feed/wayhop-apk.pem.pub
echo "https://awadak3davra.github.io/wayhop-feed/apk/$(cat /etc/apk/arch)/packages.adb" >> /etc/apk/repositories.d/wayhop.list
apk update && apk add wayhop

OpenWrt 21.02–24.10 · opkg

wget -O /tmp/wayhop.pub https://awadak3davra.github.io/wayhop-feed/wayhop.pub && opkg-key add /tmp/wayhop.pub
echo "src/gz wayhop https://awadak3davra.github.io/wayhop-feed/ipk/$(opkg print-architecture | awk '$1=="arch" && $2!="all" && $2!="noarch"{print $2; exit}')" >> /etc/opkg/customfeeds.conf
opkg update && opkg install wayhop

Entware / Keenetic · opkg (installs under /opt)

echo "src/gz wayhop https://awadak3davra.github.io/wayhop-feed/entware/$(opkg print-architecture | awk '$1=="arch" && $2!="all" && $2!="noarch"{print $2; exit}')" >> /opt/etc/opkg/customfeeds.conf
opkg update && opkg install wayhop

Entware's opkg checks no feed signatures, so there is no key to add; it checks every package against the SHA-256 sum in the feed index.

Then open http://<router-ip>:8088. Upgrades: opkg upgrade wayhop (or apk add -u wayhop on 25.12+). Your config contents are never overwritten or deleted on upgrade/removal; upgrades only repair WayHop state to owner-only permissions.

AmneziaWG 3.1 · kernel module where it fits, userspace otherwise

wget -O /tmp/install-awg.sh https://awadak3davra.github.io/wayhop-feed/awg/install-awg.sh && sh /tmp/install-awg.sh

OpenWrt and Entware/Keenetic. It adds this feed and its key when they are missing (the keys are embedded in the script), installs the kernel module when one is built for the router's exact kernel and amneziawg-go otherwise, verifies the result and rolls back on failure. --dry-run prints the plan, --uninstall removes what it installed, --restart-network restarts netifd when the amneziawg protocol handler changed. WayHop releases carry the same script as install-awg.sh, listed in their signed SHA256SUMS.txt.
