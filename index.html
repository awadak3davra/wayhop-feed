WayHop package feed

Native OpenWrt / Entware / Keenetic packages for WayHop — 0.5.7. Prefer a one-shot install instead? See the README install guide.

OpenWrt 25.12+ · apk

wget -O /etc/apk/keys/wayhop.pem https://awadak3davra.github.io/wayhop-feed/wayhop-apk.pem.pub
echo "https://awadak3davra.github.io/wayhop-feed/apk/$(cat /etc/apk/arch)" >> /etc/apk/repositories.d/wayhop.list
apk update && apk add wayhop

OpenWrt 21.02–24.10 · opkg

wget -O /tmp/wayhop.pub https://awadak3davra.github.io/wayhop-feed/wayhop.pub && opkg-key add /tmp/wayhop.pub
echo "src/gz wayhop https://awadak3davra.github.io/wayhop-feed/ipk/$(opkg print-architecture | awk '$1=="arch" && $2!="all" && $2!="noarch"{print $2; exit}')" >> /etc/opkg/customfeeds.conf
opkg update && opkg install wayhop

Entware / Keenetic · opkg (installs under /opt)

wget -O /tmp/wayhop.pub https://awadak3davra.github.io/wayhop-feed/wayhop.pub && opkg-key add /tmp/wayhop.pub
echo "src/gz wayhop https://awadak3davra.github.io/wayhop-feed/entware/$(opkg print-architecture | awk '$1=="arch" && $2!="all" && $2!="noarch"{print $2; exit}')" >> /opt/etc/opkg/customfeeds.conf
opkg update && opkg install wayhop

Then open http://<router-ip>:8088. Upgrades: opkg upgrade wayhop (or apk add -u wayhop on 25.12+). Your config contents are never overwritten or deleted on upgrade/removal; upgrades only repair WayHop state to owner-only permissions.
